# Banc_Test_Dreame
Le banc de test DREAME est un outil de diagnostic SAV conçu pour faciliter le contrôle, le dépannage et la validation des robots aspirateurs, stations d’accueil et balais laveurs DREAME. Il permet au technicien de piloter et tester individuellement les principales fonctions de l’appareil afin d’identifier plus rapidement l’origine d’une panne.
